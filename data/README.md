# Normalized activity data

Generated by `python3 scripts/normalize.py` from `raw data/` (git-ignored). Re-running overwrites `data/<year>/`.

One folder per year, each with up to four CSVs. Empty cell = no data.
Rows are filed under the year of their `date`.
`date` is always the local calendar date, and timestamps are ISO 8601 with the UTC offset that applied at the time (travel included).

## daily.csv — one row per day

| column | unit | available |
|---|---|---|
| steps, distance_m | count, m | 2016 → |
| calories_kcal | kcal | 2016 →; **active** calories until 2025-09-19, the newer band reports a larger figure from 2025-09-20 |
| active_min | min of moderate/high intensity | 2018-09 → |
| stand_hours | hours with a valid stand | 2025-09 → |
| resting_hr | bpm | 2019-12 → |
| avg_hr, min_hr, max_hr | bpm | 2018-09 → |
| sleep_min, deep_sleep_min, light_sleep_min, awake_min | min, night sleep ending that day | 2016 → |
| sleep_score | 0–100 | 2018-09 → 2025-09 |
| nap_min | min | 2021-12 → |
| weight_kg | kg, last weigh-in of the day | 2016 → 2025-10 |
| spo2_avg | % | a handful of days |
| pai_daily, pai_total | PAI score (total = rolling 7 days) | 2021-12 → 2025-09 |
| vitality_daily, vitality_total | Mi Fitness "vitality" score | 2025-09 → |
| training_load | daily training load | 2026-03 → |

## sleep.csv — one row per sleep session

`date` (wake-up day), `type` (`night` / `nap`), `bedtime`, `wakeup`, `duration_min`, `deep_min`, `light_min`, `awake_min`, `score`, `avg_hr`, `min_hr`, `max_hr`.

Before 2018-09 (old bands), some "nights" run 15+ hours. That's the band lying unworn and being scored as sleep; the values are kept as recorded.

## weight.csv — one row per weigh-in

`date`, `time`, `weight_kg`, `bmi`, `body_fat_pct`, `muscle_pct`, `water_pct`, `protein_pct`, `bone_mass_kg`, `bmr_kcal`, `visceral_fat`.
Readings from other people on the shared scale, and misreads, are dropped.

## workouts.csv — one row per workout

`date`, `type` (free_training, stretch, outdoor_walking, …), `start`, `end`, `duration_min`, `distance_m`, `calories_kcal`, `steps`, `avg_hr`, `max_hr`, `min_hr`, `avg_pace_s_per_km`, `elevation_gain_m`, `train_load`.

## Sources

- 2016-01 → 2017-05: old Mi Fit / Zepp per-year export (`raw data/<year>/`).
- 2017-05 → 2026-10: Mi Fitness export (`raw data/*_MiFitness_*.csv`). On overlapping days it agrees with the old export.
- Minute-level steps and heart rate are not kept (daily only). GPS tracks are not included.
